   responsif; hasilnya dicatat sebagai catatan, tidak memengaruhi nilai.
5. Kode dibaca: `packages/shared/src/design-tokens.ts`, semua `*.module.css`, komponen

## Token turunan: masih setia pada design system?

**Ya, diterima.** Tambahan di `packages/shared/src/design-tokens.ts` adalah token peran yang
memang dibutuhkan agar aturan kontras 4,5:1 bisa dipenuhi, bukan warna baru yang bebas:

- `--success-ink`, `--warning-ink`, `--danger-ink` — perlu, karena warna status dasar tidak
  cukup kontras sebagai teks di tema terang (`--success` di atas putih hanya 3,45:1).
- `--on-primary`, `--on-accent` — teks di atas isian berwarna.
- `--primary-soft` — alias `--bubble-out`, dipakai untuk item navigasi aktif dan pilihan
  terpilih. Wajar; satu nuansa biru lembut untuk seluruh aplikasi.
- Ukuran kerangka (`rail` 64, `list` 360, `detail` 340, `touch` 44, `bar` 56, `control` 36)
  sesuai `DESIGN.md` §2.
- Bubble keluar gelap `#1B3557` → `#1A3354`: selisihnya tidak terlihat mata, dan menaikkan
  kontras link di dalam bubble dari 4,40 ke 4,53. Diterima.

**Tindak lanjut dokumen (orkestrator, bukan `frontend`):** tabel `docs/DESIGN.md` §1 masih
menulis `#1B3557` dan belum memuat token turunan; `docs/DECISIONS.md` belum mencatat
keduanya. Samakan supaya dokumen tetap menjadi sumber kebenaran.

## Revisi, berurutan prioritas

### Wajib (menyebabkan nilai < 4)

**1. Tab Inbox: jarak tidak rata di HP dan cincin fokus menabrak huruf**
— `apps/web/src/features/inbox/Inbox.module.css` (`.tabs`, `.tab`, blok media di baris akhir)

- Sebab jarak: `min-width: var(--size-touch)` membuat kotak "Bot" (teks 22,6 px) melebar
  jadi 44 px, sementara tab lain selebar teksnya. Terukur di 390: jarak antar teks
  32,4 / 32,2 / 21,6 / 21,5 px. Lihat `inbox--390-terang.png`.
- Sebab cincin: tab tidak punya padding horizontal dan memakai `outline-offset: -2px`,
  jadi garis cincin jatuh tepat di atas huruf pertama dan terakhir, dengan sudut siku.
- Perbaikan yang sudah diuji lewat CSS suntikan (tanpa mengubah repo):

```css
.tabs {
  gap: 0; /* semula var(--space-8) */
  padding: 0 var(--space-8); /* semula var(--space-16); 8 + padding tab 8 = teks tetap di 16 px */
}

.tab {
  position: relative;
  padding: 0 var(--space-8); /* ruang untuk cincin fokus */
  border-radius: var(--radius-input) var(--radius-input) 0 0;
  /* hapus: margin-bottom: -1px; border-bottom: 2px solid transparent; */
}

/* Garis aktif tetap selebar teks. */
.tab::after {
  content: '';
  position: absolute;
  right: var(--space-8);
  bottom: 0;
  left: var(--space-8);
  height: 2px;
  background: transparent;
  transition: background-color var(--duration-fast) var(--ease-out);
}

.tab[data-state='active']::after {
  background: var(--primary);
}

/* Pengganti min-width: area tekan melebar 4 px kiri-kanan tanpa menggeser tata letak. */
@media (max-width: 640px), (pointer: coarse) {
  .tab::before {
    content: '';
    position: absolute;
    inset: 0 calc(var(--space-4) * -1);
  }
}
```

- Hasil uji: jarak antar teks 27 / 27 / 27 / 27 px di 390; 19,5 px rata di 360; 19,2–19,3 px
  di 1440. Teks "Semua" tetap di x = 16 (HP) dan x = 80 (desktop). Deret tab tidak meluap di
  tiga lebar yang diuji (360, 390, 1440). Area tekan "Bot" = 38,6 + 8 = 46,6 px.
- Kriteria lolos: (a) selisih jarak antar teks tab ≤ 1 px di 390; (b) cincin fokus berjarak
  ≥ 4 px dari huruf dan bersudut 6 px; (c) setiap tab ≥ 44×44 px di 390; (d) tepi kiri
  "Semua" sejajar judul "Inbox" dan kolom cari.

Bandingkan `inbox-memuat--1440-terang.png` dengan `inbox--1440-terang.png`. Saat kerangka

## Catatan

### Diperiksa dan diterima (tidak perlu diubah)

- Judul halaman di desktop berada di x = 80 untuk Inbox dan x = 88 untuk halaman lain.
  Kolom daftar 360 px memang lebih rapat (gutter 16) daripada halaman satu kolom (gutter
  24); menyamakannya membuat lima tab tidak muat.
- Kolom cari tanpa garis tepi (`--surface-2` di atas `--surface`). Tetap dikenali dari ikon
  dan placeholder; di mode gelap batasnya tipis (1,09:1). Bila ingin lebih tegas, tambahkan
  `box-shadow: inset 0 0 0 1px var(--line)` pada `.field`.
- Ikon tombol tema menampilkan tema yang sedang tampil (matahari/bulan), bukan pilihan
  "Ikuti sistem" — wajar.
- Tanda merek dan ilustrasi placeholder: rapi dan cukup profesional untuk sementara.

### Untuk Fase 1 (di luar cakupan penilaian ini)

- **Bedakan "inbox benar-benar kosong" dari "belum memilih chat".** Sekarang ruang chat
  selalu menulis "Pilih chat dari daftar untuk membaca dan membalasnya di sini", juga saat
  daftarnya kosong, dan panel detail ikut menampilkan pesan kosong ketiga. Saat data sudah
  ada: bila belum ada percakapan sama sekali, jadikan ruang chat satu-satunya pesan utama
  ("Belum ada chat" + kalimat Kak Sky) dan sembunyikan panel detail sampai ada chat dibuka.
- **Lebar 1024–1199 px:** dengan panel detail terbuka bawaan, ruang chat tinggal 260–435 px
  (1024 − 64 − 360 − 340 = 260). Pertimbangkan panel detail menempel hanya mulai ≥ 1280 px
  dan melayang di bawahnya (`features/inbox/use-detail-panel.ts`).
- **Lebar 320 px:** deret tab bisa digeser (336 > 320) tanpa penanda. Jarang, tetapi beri
  pudar di tepi kanan bila nanti tab bertambah.
