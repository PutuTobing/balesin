## C. Info

1. **Pembaca judul XLSX di browser** memakai regex `[\s\S]*?` atas ≤ 512 KB teks; berkas buatan (banyak
   `<t>` tanpa penutup) bisa membuat TAB pengguna sendiri sibuk beberapa detik. Berkas berasal dari
   pengguna itu sendiri — bukan vektor serangan ke orang lain.
2. **Konfirmasi identitas untuk ekspor dikirim di body POST** (password + kode) — benar (bukan di URL);
   tidak masuk cache Query (panggilan `client.download` langsung).
3. **Komentar CSAT pelanggan** belum ditampilkan di UI; saat ditambahkan, tampilkan sebagai teks (data
   pelanggan tak tepercaya) dan pertimbangkan penyamaran data pribadi.
