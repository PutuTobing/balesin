# Balesin

Inbox customer service tim untuk WhatsApp Cloud API resmi + Telegram, Email, Messenger,
Instagram. Self-hosted, white-label. Dibuat oleh PT Sky Base Technology Digital (Sky Tech).

> Status: tahap pengembangan awal. Lihat `docs/PROGRESS.md`.

## Mengembangkan dengan Claude Code

1. Buka folder ini di VS Code, jalankan Claude Code.
2. Pilih model untuk orkestrator (`/model`).
3. Ketik `/lanjut` — orkestrator mengerjakan roadmap bersama subagent di `.claude/agents/`.
4. Cek `docs/BUTUH-TOBING.md` untuk hal yang perlu Anda siapkan.
5. `/audit` kapan saja untuk audit tampilan, bug, dan keamanan.

Dokumentasi lengkap ada di `docs/` (mulai dari `CLAUDE.md`).
